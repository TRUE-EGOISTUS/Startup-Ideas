## Шаг 5. Оценка компании 2–3 методами (шаг 5)
### Метод 1: Венчурный (Venture Capital Method)
* Прогноз выручки через 5 лет (год 5) по conservative сценарию: ~6 млн руб/мес → годовая выручка 72 млн руб.
* Мультипликатор выхода (EV/Revenue) для fast-growing marketplace: 3–5x. Берём 4x.
* Exit Value = 72 * 4 = 288 млн руб.
* Требуемая доходность инвестора (для pre-seed стадии) – 40% годовых на 5 лет: множитель (1+0.4)^5 = 5,38.
* Post-money valuation = Exit Value / 5,38 ≈ 53,5 млн руб.
* При инвестиции 300 тыс руб (0,3 млн) доля инвестора = 0,3 / 53,5 ≈ 0,56% (нереалистично мало). Значит, требуемая доходность для таких малых сумм не 40%, а скорее 100% годовых (инвестор хочет 10x за 5 лет).
* Пересчёт с 100% годовых: множитель 2^5 = 32 → Post-money = 288/32 = 9 млн руб.
* Pre-money = 9 – 0,3 = 8,7 млн руб.
__Диапазон pre-money (по венчурному методу): 8–10 млн руб.__

### Метод 2: Мультипликаторы (Comparables)
Аналоги: Wellfound, Upwork, фриланс-биржи. Мультипликатор EV/ARR для быстрорастущих платформ на ранней стадии – от 2 до 5.
Наш ARR через 12 месяцев (base) = 1,18 млн руб/мес * 12 = 14,16 млн руб.
Оценка = ARR * мультипликатор:
* Нижняя граница (2x) = 28,3 млн руб
* Верхняя граница (5x) = 70,8 млн руб
  С учётом того, что компания ещё убыточна на старте, инвесторы дадут ближе к нижней границе.
__Диапазон: 25–35 млн руб__ (post-money). Pre-money (если раунд 0,3 млн) = 24,7–34,7 млн руб.

### Метод 3: DCF упрощённый (только для демонстрации)
Прогноз свободного денежного потока (FCF) на 5 лет по base сценарию (помесячно, затем годовые):
Год 1: FCF ≈ –0,3 млн (начальные инвестиции)
Год 2: 5 млн (после выхода на операционную прибыль)
Год 3: 12 млн
Год 4: 25 млн
Год 5: 45 млн
Ставка дисконтирования (WACC для стартапа) – 35% (высокий риск).
Коэффициенты дисконтирования: 0,74; 0,55; 0,41; 0,30; 0,22.
PV(FCF) = –0,3*1 + 5*0,74 + 12*0,55 + 25*0,41 + 45*0,22 = –0,3 + 3,7 + 6,6 + 10,25 + 9,9 = 30,15 млн руб.
Терминальная стоимость (год 5, рост 5%, ставка 35%): FCF5*(1+g)/(r-g) = 45*1,05/0,30 = 157,5 млн; PV терминальной = 157,5*0,22 = 34,65 млн.
__Итого DCF-оценка = 30,15 + 34,65 = 64,8 млн руб__ (post-money).
Но DCF на ранней стадии очень чувствителен к допущениям, поэтому этот метод даёт верхнюю границу.

## Шаг 6. Факторы, повышающие оценку, и план действий (шаг 6)
### 5 ключевых факторов стоимости для нашего проекта:
1. __Темп роста ARR__ – чем быстрее выручка удваивается каждый квартал, тем выше мультипликатор.
2. __LTV / CAC__ – жизненная ценность клиента (специалиста или компании) должна превышать стоимость привлечения минимум в 3 раза.
3. __Retention (кохортный анализ)__ – доля активных пользователей через 3 и 6 месяцев. Цель >40% через 6 мес.
4. __Unit economics (для платных задач)__ – маржинальность после комиссий и переменных затрат.
5. __Качество команды и скорость итераций__ – демонстрация способности быстро выпускать фичи и привлекать первых платящих клиентов.

### План действий на 4–8 недель для повышения оценки:
| Что делаем | Как измеряем	| Ожидаемый эффект |
| ---------- | ------------ | ---------------- |
| Привлечь 10 пилотных компаний-партнёров для размещения задач с вознаграждением | Количество компаний, разместивших платную задачу	| Рост выручки и доказательство спроса (повышает LTV) |
| Внедрить реферальную программу и замерить K-factor | Коэффициент виральности >0,2	| Снижение CAC, увеличение темпа роста ARR
| Провести 2 когортных анализа (после 30 и 60 дней)	| Retention D30, D60 | Если retention >30%, оценка может вырасти на 30-50% |
| Собрать отзывы и кейсы успешного найма через платформу | Кейсы с компаниями, которые нашли сотрудника через задачи | Укрепляет мультипликатор (доверие к бизнес-модели) |
| Оптимизировать воронку: из 500 регистраций получить 100 активных (20%) | Конверсия регистрация → выполнил задачу | Улучшает unit economy и LTV/CAC |

### Итоговый вывод по оценке
Компания находится на pre-seed стадии. Диапазон pre-money оценки 8–30 млн руб с центром 18 млн руб. Для повышения оценки до 50+ млн руб за 6 месяцев необходимо:

* Достичь ARR 10 млн руб (ежемесячная выручка 800 тыс руб)
* Доказать LTV/CAC > 3
* Удержать первых 20 платящих компаний не менее 6 месяцев.
